# P5 柳溪庄总督会面与委托

负责人选定在任人物拜访与办事。基线 `9b975cc1b1809b620415aa64101e74df8b351252`，依赖 P4-GOV 和 P3-CHR。只有本包提前放行。[ADR-018](../../docs/architecture/decisions/ADR-018-estate-visit.md) 冻结角色权限、任务/领奖语义及存档兼容。

| 任务 | 模块 | 工作与验收 |
|---|---|---|
| P5-VISIT-001 | QUEST | 庄簿委托与对话选择 |
| P5-VISIT-002 | CHR | 在场人物事实与个人经验收据 |
| P5-VISIT-003 | CAMP | 战役日结、委托与持久化一致性 |
| P5-VISIT-004 | APP | 访问鉴权、会话与存储故障重试 |
| P5-VISIT-005 | BOOT | 正式沙盒受信入口 |
| P5-VISIT-006 | UI | 庄署名册、总督会面、交差和任务簿 |

QUEST、CAMP、UI 独立工作树，CHR、APP、BOOT 由主 Agent 接入。并行编写后在同一候选集成，独立 QA 使用上版物理存档、窗口及客户端包；独立审查验证真实来源、人物失效与冷恢复。
