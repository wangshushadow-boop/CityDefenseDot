# P4 总督治理执行计划

负责人选择从已有家族成员中任免总督。启动基线 `5e1ad4c39e7362b8b3a4b86f50405b279c35086c`。此工作包从 P4-SET 拆出；其他 P3、P4 工作包保持原门禁。正式行为、存储及预览在 [ADR-017](../../docs/architecture/decisions/ADR-017-governor.md) 冻结。

| 执行任务 | 所属模块 | 工作与验收 |
|---|---|---|
| P4-GOV-001 | SET | 庄邑任免及治理日结 |
| P4-GOV-002 | CHR | 家族成员资格与领地作用域技能 |
| P4-GOV-003 | CAMP | 战役时钟、任期与存档一致性 |
| P4-GOV-004 | APP | 现有已鉴权人物命令与原子回执 |
| P4-GOV-005 | BOOT | 沙盒受信入口 |
| P4-GOV-006 | UI | 人物页治理及真实桌面交互 |

六项开发任务基于同一冻结端口。领域、战役、界面由隔离工作树编写，CHR、APP、BOOT 由主 Agent 处理；交付顺序为 SET 与 CHR、CAMP、APP 与 BOOT、UI，最后在同一候选上独立复验。T-GOV-01 实测任免及技能对日结的量化影响，T-GOV-02 覆盖失格、幂等、旧档和回滚。

六项任务已通过最终集成。实际提交、退出码、首次失败及独立证据见[验收记录](../reports/stages/P4-governor.md)。
