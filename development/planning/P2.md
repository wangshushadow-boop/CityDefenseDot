# P2 实时战争

负责人授权从 P1 验收提交 005d777 启动。沿用 ADR-011 至 013、已有 Session 和 Mission，分别落实领域单写入。首批四个独立工作树分别负责 Mission 来源、COM 游戏动作、MOV 路径与 FORM 队形。各包 001 是可先验证的领域任务，002 接上同一生产野战入口，并以完整条件验收。以任务 JSON 为写入白名单。

| 批次 | 工作包和验收 |
|---|---|
| 1 | MIS-RT-BATTLE、COM、MOV、FORM。冻结野战来源到队伍的归属，验证部署与增援、方向输入、导航及队形。 |
| 2 | 依前置启动 BAI、RULES-FIELD、INPUT、VIS-BATTLE。UI、玩家及 AI 经合法命令进入唯一权威 Mission。 |
| 3 | BAI-T、BAI-F、BAI-I、RESULTS。每一来源槽有且只有一个终态，支持未入场。 |
| 4 | CAM、AUD-BATTLE、UI-BATTLE，以及经授权的桌面装配、原创或许可明确的临时素材。 |
| 5 | FIELD-INTEGRATION，500 人混合野战完成 AT-04；另测 1000 人压力以及千人分波撤退的 AT-05 战场切片。 |

使用种子 241124 与锁定的 1080p 负载，同步记录 1% low、帧 P95、tick P95 和积压；500 人平均至少 60 FPS、帧 P95 至多 20 ms；1000 人平均至少 30 FPS、帧 P95 至多 40 ms。记录 RTX 3090 的实测和 8 GiB 目标设备的实际测试状态。

野战兵源分队须经[ADR-014](../../docs/architecture/decisions/ADR-014-field-source-teams.md)签核。来源索引、动作、路径队列和布局可独立验证。
