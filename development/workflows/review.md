# 独立审查

Reviewer 使用任务基线与候选 commit 进行 diff 审查，不只读开发者摘要；QA 与实现者分离（无子 Agent 时，主 Agent 在新审查轮次独立重查并声明非独立模型）。

重点：写范围/父子目录排除、静态依赖、数据唯一所有权、权限、异常与资源守恒、版本兼容、并发/生命周期、内容授权、性能。逐条核对任务验收与实际测试，不接受空方法、硬编码通过、禁用测试、仅演示或伪证据。QA 独立运行测试，核对测试确实执行指定用例；适用时使用真实场景、固定种子和版本。

输出 [审查报告](../templates/review_report.md)，判定 PASS / CHANGES_REQUIRED / BLOCKED。阻断项必须修复且重审；低风险项需明确接受理由，不可暗中降低 MUST。人工手感、质量和可访问性不能仅凭自动化测试判定。
