# 阶段验收（质量门禁）

主 Agent 汇总候选任务、实际测试和审查，检查 [阶段计划](../planning/roadmap.md) 及总体设计 §19/22/23。每个阶段的 `GATE-Pn` 是全局门禁，不可委派为自行标记完成；上游任务必须 DONE，必需证据与批准完整，所需的阶段能力实际工作。阶段仅验证本阶段范围，后续功能所需 AT 只记录切片证据和完整测试 NOT_RUN；不得把后续需求删掉。

P0 必须有基准环境、真实负载（500/1000 混合实体、动作、蒙皮、导航与专服实验）、对比结果与选择理由、已批准技术栈及关键契约 ADR。达不到目标必须调整路线并重新验证或记录 BLOCKED，不能用空场结果替代。P1–P7 真实测试按冻结环境执行；P7 需要所有 MUST 需求与全部本体 AT-01–16 验收通过、性能/稳定性、原创内容授权、安装/迁移与负责人实际试玩/发布批准。P8 独立验证 NAVAL、AT-17 与本体回归。

报告必须引用已集成 commit、测试 ID/命令/退出码、版本/设备/种子、原始证据、未运行项、风险及验收者；可用 [阶段报告模板](../templates/stage_report.md)。没有证据不得通过；未达到的阶段状态为 PARTIAL 或 BLOCKED。用户审批记录包含决策、时间和关联 ADR，不伪造确认。
