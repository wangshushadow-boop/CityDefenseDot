# 实现与自测

- 输入：已细化任务 JSON、基线 commit、所属 SDD、公共契约、允许/禁止路径、需求及测试 ID。主 Agent 先确认具体行为可测试、前置已集成、任务不涉及未批准接口。
- 任务 Agent 先检查 `pwd`、Git root、HEAD、初始 diff；读父模块入口、权威设计、直接依赖的公开接口。需要新增规则/状态机/错误分支时在授权 SDD 中补充；冲突提交 ADR。
- 实现代码、配置和测试。公开接口仅在明确许可、批准 ADR 且有版本/消费者迁移方案时变更。高频逻辑与持久逻辑、AI 决策与执行系统严格区分；引擎表现不得反向写领域状态。
- 单测覆盖正常、边界、非法状态、权限、回滚/幂等；涉及性能、存档、网络或跨模块契约时添加对应测试。仅在真实命令执行后记录退出码，记录实际运行/跳过的测试数量。
- 使用 [任务报告](../templates/task_report.md) 提交结果，附 diff 或候选 commit、测试日志/证据路径、未决事项。未达到交付不得声明 DONE。主 Agent 分配审查而不是开发者自我批准。
