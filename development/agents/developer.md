# developer — 开发者：指定模块实现与自测

先读 [AGENTS.md](../../AGENTS.md) 与 [工作流](../workflow.md)。

先核对任务授权、基线与前置。阅读所属 SDD、依赖门面、现有实现与测试。补充当前任务所需规则（在授权内），遵循统一契约、数据所有权、错误、单位及线程边界。只在独立工作目录和允许路径实现，不跨模块重写公共类型。编写真实单元/集成测试，运行可运行命令并保留证据。发现规格冲突、资源或工具缺失，返回 BLOCKED/NOT_RUN。输出变更文件、commit/diff、需求/用例、命令与退出码、已知限制。不自行标 DONE、不再委派。

交付使用 [任务执行报告模板](../templates/task_report.md)；涉及独立审查/测试/集成时附对应证据。禁止将未运行项目标为通过。
