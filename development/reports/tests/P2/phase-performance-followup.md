# P2 野战性能的架构判断

已合入的局部优化没有消除整场超时。没有证据支持再调一个渲染开关、一次物理查询或一项算术，就可以通过当前门槛。现有公开端口已经能支持 MIS-RT 内的下一项差分实验。只有需要向别的逻辑模块开放批数据、阶段生命周期或原生 ABI 时，才需要先冻结新增的跨模块约定。现有数据所有权可完整保留。

## 最终整场证据

生产树 53e7a5b 的六个 1080p Forward+ 图形进程均退出 0，预算判据退出 1。每轮实际接敌，120 步预热，再测 360 个连续权威步。500 人三轮 2.33–2.36 FPS，帧 P95 450.920–468.885 ms，权威 P95 43.759–44.821 ms；1000 人三轮 1.07–1.24 FPS，帧 P95 889.219–1027.825 ms，权威 P95 92.387–105.093 ms。相对 16.667 ms 固定步预算，分别需要缩短约 62%–63% 和 82%–84% 的耗时。所有试次均持续积压。测试机使用 RTX 3090，GPU 的 P95 为 10.574–11.130 / 14.258–14.820 ms。开发机有同期 headless 工作；该显卡的实际长帧与权威超时已经成立。8 GiB 参考设备是另一个尚未执行的测量条件。详见仓库 `development/reports/tests/P2/field-benchmark-final/`。

诊断中的早期固定种子 120 个接近步逐样本计时，1000 人每步总时间扣除整段 think 与 walk 后，余量 P95 仍有 25.315 ms；再扣除 fight 后为 17.476 ms。这是同一次执行的算术分解，实际逻辑均有运行。018 的精确球扫复用、原有编队/视图投影 A/B 和原生位姿批次均实测了收益，数量级为亚毫秒至数毫秒。原生相对同布局 GDScript 的单一位姿算术节约约 0.19 ms。记录分别在 `development/reports/tasks/P2-FIELD-INTEGRATION-018.md`、`development/reports/tests/P2/field-projection-ab.json`、`development/reports/tests/P2/field-native-spike/` 及 `development/reports/tests/P2/field-phase-profile.json`。

## 本次新增的模块内差分

从 07eb8e8 分别归档原版和实验版。两份代码同样计时。实验只改 MIS-RT 内 field_pipeline 与 field_brains 之间的调用，按 MOV 现有阵容令牌、各编队成员/控制/命令修订判断名单是否稳定；稳定时复用 MOV 公开批读的连续位置，按实际变化提交生命、弹药、士气，继续执行现有的分组感知、个体调度、视线、实时授权核验和战斗。令牌、修订或人数变化走原全量路径；失败按同一步 checkpoint 撤销缓存。此前试验改动的是 FORM 名册深复制和 HUD/VIS 实体读取，这次实际计时的对象是每步的 MIS-RT → BAI 名册重建。

以下为 headless，单位 ms，每档各一对进程。保持 60 Hz，按同一四编队路线接战，接敌后 120 步预热再取 128 步，独立看同一进程内的完整权威步及其内部计时。每 16 步对所有 Mission 实体、系统回执、HUD、输入和视觉投影取摘要。

| 人数 / 方案 | AI 名册索引 P50 / P95 | 完整 AI 阶段 P50 / P95 | 整个权威步 P50 / P95 | 稳定名册步数 |
|---|---:|---:|---:|---:|
| 500 / 基线 | 2.783 / 3.300 | 13.331 / 16.067 | 40.373 / 49.992 | 0 / 128 |
| 500 / 实验 | 0.665 / 0.830 | 11.014 / 13.259 | 37.051 / 48.927 | 124 / 128 |
| 1000 / 基线 | 5.582 / 12.582 | 28.162 / 39.039 | 79.705 / 104.014 | 0 / 128 |
| 1000 / 实验 | 1.443 / 12.228 | 24.102 / 37.008 | 75.995 / 100.129 | 121 / 128 |

500 人在 977 步接敌，记录 52 次发射、34 次命中、3 次倒地；基线和实验全部 8 个摘要相同。 1000 人在 917 步接敌，记录 53 次发射、29 次命中、6 次倒地；基线和实验全部 8 个摘要相同。

实验工程采用真实三层 AI、撤权、伤亡和骑乘的管线回归 335 项，另有独立 brains 1,316 项、AI 事务 29 项和 FORM 事务回归，均实际退出 0。本次抽样不覆盖所有可能的模组、跨网或长期并发，单轮共享 CPU 的 P95 用于评估数量级。

千人实验在 128 步内有 121 步保持名册，另外 7 步恢复全量路径。名册索引 P50 从 5.582 降到 1.443 ms，P95 仅从 12.582 降到 12.228 ms。千人整步 P95 从 104.014 降到 100.129 ms，仍超过 16.667 ms 门槛。局部提速不能作为阶段过关依据，可复核文件为 `runtime-index-ab/summary.json` 与 `runtime-index-ab/evidence.zip`。

## 可选路线与归属

| 选择 | 工作与理由 | 需要评审的位置 |
|---|---|---|
| A，默认。保留 Godot 和类型化 GDScript | 先把从名册建立到感知、移动、伤害的完整一条热路径按字段和生存期拆开。现有 MOV.bind_roster/read_poses、BAI.publish/advance 与 COM.field_view 已有世代、位置和状态语义。先在自己的模块里用这些端口做逐步差分；连续内存只在读者确实需要时生成。 | 首个 MIS-RT 试验已执行。下一批若需例如 COM 发出自上次提交以来变化的名册行、MOV 暴露完整阶段缓冲或 BAI 借用缓冲跨调用，先评审读写者、撤销与失效事件，冻结局部端口后各模块才并行。 |
| B，备选。按 ADR-011 试验原生批计算 | 保留同一参考实现、领域命令与 Jolt 窄相碰撞。用 A 的相同输入隔离一个完整、高耗时计算批，例如 BAI 感知的空间索引/候选列表，并保持真实遮挡与排序。位姿试验已验证能加载原生 DLL、跨语言空调用与真实数据的代价，但不支持仅下沉位姿换算。 | 新原生 ABI、装配和发布依赖需要新 ADR 和负责人审批。要求原生与脚本实现对同一输入逐项一致，测量从生产者到领域消费及回滚的总成本，再决定是否启用。 |

MIS-RT（`game/mission/runtime/`）拥有作用域、实体编号/世代、固定步与提交屏障。FORM 拥有成员、编队和指挥修订。MOV 拥有位姿、路径、导航修订的使用及可回滚移动。COM 拥有生命、武器、弹药、士气、弹体和伤害。BAI 拥有感知、调度令牌和意图；BAI-T/F/I 只通过许可接口影响订单或个体输入。INF-ENGINE 拥有真实引擎查询及物体代理，VIS/BOOT 在最新提交之后消费授权投影，TEST 独立验收。备选路线的 NATIVE 只持有有界临时输入输出，若启用，CON 管版本、BOOT 管装配。上述模块归属取自 `development/planning/module_owners.json`，读命令仍遵循 `docs/architecture/dependency_policy.md`；任务分配时应按最长前缀排除独立子模块。

## 下一批的差分与验收

1. 选择一个热点和唯一写者，先从生产树冷提取 baseline。以相同四编队指令、60 Hz、种子 241124 重放 500/1000 人；记录每个真实固定步及被改阶段的 P50/P95。保持人数、后备、动画、指挥、真实 LOS/Jolt 和采样窗口一致。用已提交单一权威状态构造测试输入，避免独立副本变成第二份真值。
2. 首批如新增读视图，限定到当前 Mission、名册世代、阶段和 tick。审核失败/过期时的既有错误；旧句柄、同一步中途撤权、队伍键类型、撞击、伤亡后同索引补员、撤退、导航修订、撤销后重试和跨作用域都以旧实现作参照。在每个事务边界比较成员顺序/世代、位置、控制版本、伤害/弹药、事件及 MissionResult；任一差异记录首个 tick 和字段。核对 `field_pipeline`、`field_brains`、`ai_transaction`、`formation_transaction`、`motion_batch`、`field_path_retention` 的真实退化案例。
3. 给基线/候选交替执行各三轮，独立 QA 重算原始样本。可合入的局部提速应在整条路径（含构造、转移、提交与回收）多次复现；只在切片可见的收益保留为实验。阶段继续使用 §19.4 原判据，500 人 ≥60 FPS 且帧 P95 ≤20 ms，1000 人 ≥30 FPS 且帧 P95 ≤40 ms，两档固定步 P95 均 <16.667 ms 且无持续积压。若新接口改变公开字段、时序或数据归属，按 ADR/迁移和需求追踪工作流处理，由负责人签核。
