# P0 独立 QA 实测

QA 使用开发者以外的原生 qa 子 Agent；集成后另由主 Agent 复跑。Python 和 Godot 的完整路径及硬件见 ENV 任务报告。检验在 Windows 本机，正式模块测试和 AT 均保持 NOT_RUN。

| 对象 | 独立执行与真实结果 |
|---|---|
| ENV、CRITERIA | 仓库结构、镜像检查和 Godot 版本命令退出 0，RTX 3090 及引擎散列独立验证。QA 核对 GDD §19.4 原始预算与故障/逐轮判据。 |
| CONTENT | 最终 runner 退出 0；编辑器导入、编译、导出 PCK 与无源目录重载共四项退出 0，11 个坏例分别退出 2（预期），相同有效定义 624 B，PCK 8988 B。 |
| NAV | 两项通过；关/开/关/开修订 3/4/5/6，重复关门前后累计通过数同为 64，等待峰值 155，最终 256/256，3 次旧路由拒绝。136 次路径查询 P95 4 µs。 |
| CONTRACTS | 8 组 unittest 退出 0。单独重放协议版本 true 和编队 ID true，二者都被拒绝。 |
| NET-001 | 沙盒内回环失败，runner 退出 1。允许本机环回后重跑退出 0，1 客户端正常/故障及 4 客户端正常/故障 tick P95 依次为 106/153/159/283 µs；每档 21 项断言通过。故障两档越权拒绝 3/12，重复拒绝 13/51，10 个客户端会话终态全部与服务器相同。 |
| BATTLE 首版 | 仅复跑 500 人配置，三轮平均 684.3/655.0/653.0 FPS，P95 3.40/3.53/3.53 ms，runner 退出 0。人数口径不符合 GDD，首版 1000 人未另行 QA。 |
| BATTLE 修正版 | 在固定提交 `c4c6b80` 用桌面 Vulkan/RTX 3090 独占 GPU 复跑。每档三轮，2,160 个 tick 中在镜活人和坐骑始终为 500+100 或 1000+200，额外尸体峰值 39/70。两条命令均退出 0，另行解压重算全部 6 份哈希和统计通过。 |
