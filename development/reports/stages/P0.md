## 修复与验收边界

- 首版 500/1000 人的帧时达标，活跃人数最低却只有 460/938，验收判失败。修正版将尸体独立计数并在同 tick 补员。范围检查同时修复了部分单位出镜和刺击反馈。两版原始数据均保留。
- 环境中的 python3 商店别名不可用，改用已核实的 Python 3.12.14。初次受限沙盒的本机环回握手超时，获准在 127.0.0.1 运行后完成复验。编辑器首轮返回 0 但记录错误，驱动按失败处理并修复了导出预设。
- 契约向量曾接受 bool 充当版本或编号；内容工具曾接受重复标记或通配挂点。分别补充严格类型、角色/精确名称校验及负例后独立重跑通过。Godot 默认 JSON 解析丢失部分数字词法和重复键，须按已批准的端口策略保留原始字节。
- 战场只验收本机、本次原创程序化资产和短周期混合负载。正式中画质资产、8 GiB 参考设备、完整战斗/导航合场及长期稳定性均未实测。导航覆盖单向窄桥、门洞及斜坡。网络覆盖本机真实连接和合成负载，真人、公网及完整玩法容量仍待验证。
- 原创样件已导出并重载 PCK。零售 Windows 可执行包导出因本机缺对应模板为 NOT_RUN；任意 Unicode NFC、全消息编解码、实际游戏存档原子恢复及人工手感也为 NOT_RUN。93 条正式需求维持 NOT_IMPLEMENTED，208 项模块测试和 AT-01–17 均为 NOT_RUN。
