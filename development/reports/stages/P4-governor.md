# P4 总督治理验收

**P4-GOV 通过。** 2026-11-25，负责人选定的家族总督流程在 Windows 客户端完成验收。生产版本 `0ca0100`，Godot 4.7.2 Standard，GDScript。P4 阶段整体为 PARTIAL，P3 整体及 P2 性能维持原记录。[原始授权和默认规则](../../../docs/architecture/decisions/ADR-017-governor.md) · [任务与集成记录](../tasks/P4-governor.md)

## 游玩入口

在沙盒中创建人物，或载入已有家族的存档。打开「人物 → 领地治理」，选择「接管柳溪庄」，可任免已有的成年家人，查看管理与统御对次日繁荣和忠诚的预计贡献。点击「休养一日」后可把上次实结与预测对照。默认初始家族有一名可任职的成年亲族；家主主持家务。在任者被俘、离家、死亡或继任家主时，职位转为空缺，之前的账簿仍归当时在任者。家人在岗位上不会同时占用出征兵源。

| 同一庄邑、同一候选人的三次实测 | 当日繁荣实际变化 |
|---|---:|
| 总督空缺 | +0.1 点 |
| 任命管理为 2 的族人 | +0.4 点 |
| 该人物通过权威经验结算将管理升至 22 | +2.4 点 |

治理指标各为 0 至 100 点，实际变化包含基础、任职贡献和上下限。旧家族在接管当天建立自己的庄邑账簿，之前经过的日期不追算。[客户端实机截图](../tests/P4/governor/governor.png)
