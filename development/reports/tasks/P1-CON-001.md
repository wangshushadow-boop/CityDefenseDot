# P1-CON-001 公共契约与版本管理

**CANDIDATE**。开发者 p1con，在独立 detached worktree `.worktrees/p1-con` 实现，基线 `f72d1cbd700228a4b2b70098fa0308364393f9f4`。候选以工作区 diff 交付。任务依据 CON SDD v0.1、GDD §17.4、公共契约和已签核 ADR-012，关联 BAT-03、NET-05、SAV-03。

## 交付

- `game/contracts/result.gd` 提供 Result、错误和本地化消息键。 `values.gd` 校验带类型 UUIDv4、DefId、有限整数、毫米/微弧度和带 Mission 与 generation 的句柄。
- `game/contracts/canonical.gd` 提供 encode、decode、decode_source 和 hash_value。编辑源支持非规范排版和合法 JSON 转义，在插入字典前拒绝解码后重复的键，从原始词法检查整数语法和 ±(2⁵³−1)。线解码还逐字节核对规范结果。 `unicode_nfc.gd` 与 `unicode_data.gd` 执行 Unicode 15.0.0 的规范分解、组合标记稳定排序和规范组合，包括 Hangul。
- `game/contracts/schema.gd` 覆盖命令、回执、查询、事件、快照、ChangeSet、六种意图及批次、EncounterSpec、MissionResult、FormationOrder、握手与迁移。validate_shape 校验并返回独立深层只读快照。validate_settlement 检查来源区间、恰好一次的终态、版本和摘要。check_compatible 对协议、内容 API 和内容哈希逐项验证并返回兼容信息。合成 SaveHeader v0 通过副本迁至 v1。
- Godot 的 String 无法保留 U+0000。输入可用 PackedStringArray 的段表示 NUL 之间的文本，解码将其表示为只读 Array[StringName]，各段间隐含一个 NUL。普通 JSON 数组使用 Array。规范字节维持 JSON 字符串，键和标识各自执行字符规则。Array/Dictionary 的单容器预算 65,536 项，深度预算 64。源码生成器为 `game/tests/p1/contracts/generate_unicode.py`。
- 权限核验使用 `git status --short --untracked-files=all`。六个生产脚本、四个测试/生成文件和本报告均在任务授权范围。未修改 ports、状态或架构文档。MoveIntent.speed_fraction 的候选精度为百万分之一，领域输入为 0..1，线数据为 0..1,000,000 的整数，半单位远离零。由主线程办理该候选的 ADR 和签核。
