# P1-SHRULE-001 · 公共数值规则

纯函数按作用域和优先级过滤互斥组，按固定加减、比例乘法、限幅的次序生成分项。货币可接受整数分子和分母并精确向上或向下取整。概率计算显式注入独立随机流。

Windows / Godot 4.7.2，执行 `--headless --path game --script res://tests/p1/rules/run.gd`，T-SHRULE-01/02/03 和 P1-RULES-RNG 全部通过，退出 0。覆盖输入反序、互斥天赋、不同 scope、买卖方向、最大安全整数的半单位、异常值与非法范围，以及随机流恢复复现。领域专属的伤害与市场公式由其对应阶段实现。

复审修正了注入的无效 RNG 返回 0.5 会被截断的问题，改为按原始类型验证 uint32，并增加失效输入回归。
