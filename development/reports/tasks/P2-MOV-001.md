# P2-MOV-001 路径请求预算、共享与版本失效

**开发候选**。基线 `005d777101654e67263e04fc6f2965403222e0b4`，隔离工作树 `.worktrees/p2-movement`，开发者 p2movement。所属模块 MOV，关联 NAV-01、BAI-02、BAI-06、COM-04。规格和完整验收条件见 [MOV SDD](../../../docs/systems/game/mission/movement/README.md)。

## 变更

[路径队列](../../../game/mission/movement/path_queue.gd) 接受任务内注入的已有导航适配器，以起点、目标、移动类型共享相同请求。队列按优先级和到达顺序调度；每次提交的工作消耗本 tick 的剩余额度，重复处理同一 tick 不能获得新的额度。等待队列和已完成缓存各有容量上限。旧票据、变更尚未同步的导航、已经释放的任务及超限请求返回带原因的错误。调用者只能读到独立的路径副本。无公共契约或持久格式变更。

[测试驱动](../../../game/tests/p2/movement/run.gd) 加载了带四个区域、三个真实 NavigationLink3D 的[导航场景](../../../game/tests/p2/movement/links.tscn)，使用正式 INF-ENGINE 接口。生产文件、模块导航、两个专属测试文件及本报告均位于授权路径内。

## 实测

从工作树根目录运行以下命令。Godot 为 4.7.2.stable.official.ed1daf0bf。固定导航几何和输入序列无需随机种子。

```powershell
$godot = 'D:/Program/Godot/Standard/Godot_v4.7.2-stable_win64_console.exe'
& $godot --headless --path game --log-file "$env:TEMP/p2-mov-tests.log" --script res://tests/p2/movement/run.gd
& $godot --path game --resolution 640x400 --log-file "$env:TEMP/p2-mov-window.log" --script res://tests/p2/movement/run.gd
& $godot --headless --path game --log-file "$env:TEMP/p2-mov-engine-regression.log" --script res://tests/p1/engine/run.gd
python -B ci/gates.py dependencies
```

| 用例 | Headless | Windows 客户端 | 观察 |
|---|---|---|---|
| T-MOV-01 | PASS，退出 0 | PASS，退出 0 | 关闭时目标不可达，门、梯与缺口的链接依次开启。同步前拒绝交付，确认新版本后路径到达目标。再次关门后旧可达路径失效。 |
| T-MOV-04 | PASS，退出 0 | PASS，退出 0 | 500/1000 个步、骑路径请求分别共享 20 条不同走廊，各用 5 个固定步完成；稳定后查询数为 0。额外的 500/1000 条互不相同的路径分别在 125/250 步完成，峰值待处理 24 项，每步最多 4 次真实引擎寻路。 |
| 依赖及 P1 引擎回归 | PASS，均退出 0 | — | 引擎用例零失败，生产依赖图零违规。 |

Windows 图形驱动报告 Vulkan 1.4.325 / Forward+ / RTX 3090。共享压力序列在 headless 下为 4,641 / 9,351 微秒，在图形模式下为 5,776 / 9,063 微秒，含入队、查询、全部结果读取及测试断言。以上是整段耗时。完整 500/1000 人战场的 FPS、路径 P95、T-MOV-02 的真实人群避让和 T-MOV-03 的骑乘运动约束尚未测试。

当前 INF-ENGINE 对每次地图变化只提供一个任务内导航版本，路径响应含路点和可达性。版本变化时 MOV 保守丢弃该任务的旧结果和挂起请求；细到单条链路的相关路径失效仍待路径元数据。步、骑的请求缓存已隔离，导航层级的可通行能力筛选及野战装配由后续任务完成。
