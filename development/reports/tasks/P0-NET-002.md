## 受限历史的固定时序

服务端按 tick 缓存原点、目标位置、格挡与盾牌状态，共七份快照，含当前和之前六步。每连接有单独的模拟时钟偏移、动作锚点和去重记录。驱动收到分配给本连接的锚点后，通过真实 ENet 发送动作；服务端按预设接纳时序在第 3、6 或 7 步处理并校验映射后的 tick。该输入轨迹用于控制时间边界，时钟同步与公网 RTT 需后续实测。

| 时序 / 反例 | 判断来源 | 各连接预期 |
|---|---|---|
| 历史姿态中近战在距离内，接纳时目标已走出范围 | 同一历史样本中的双方位置和防御 | 命中；当前姿态反算未命中 |
| 历史格挡、历史盾牌 | 目标格挡/盾与相对位置取同一 tick | 分别拦截 |
| 弹体已在过去释放 | 仅取历史释放点；接纳后下一权威 tick 移动，使用该步移动障碍做扫掠 | 命中当前移动障碍 |
| 历史年龄 6、7，声称未来和伪造窗口内的时刻 | 连接锚点、时间边界和实际环形槽 tick | 分别受理、过期、未来、锚点不符 |
| 同一攻击重复两次 | 连接与动作标识组成的幂等键 | 一次应用、一次拒绝 |

- 64 连接，两个进程退出码 [0, 0]。当前姿态与历史近战判定相反 64 次，弹体在接纳后的权威步命中 64 次，移动拒绝的重复/旧序/越权分别为 128/64/64。失败断言 无。

## 容量与决策边界

64/128 是回环合成连接数。四秒量级的简单运动场景不覆盖真人手感、生产战场 AI、真实跨网延迟、所有丢包模型、8h 稳定性和正式模块/AT。六步（200 ms）可作为继续测试的候选上界；公平性、实际序号映射策略和生产冻结由负责人评审。
