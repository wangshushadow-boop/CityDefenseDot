# P2-COM-001 四向游戏动作与接触去重

开发候选基线为 `005d777101654e67263e04fc6f2965403222e0b4`，模块 COM，角色为开发者 p2combat。工作树为 `.worktrees/p2-combat`。关联 COM-01、COM-05 和 T-COM-01、T-COM-05。[COM 设计](../../../docs/systems/game/mission/combat/README.md)

`melee.gd` 使用已有 AttackIntent 和 BlockIntent，以离散 tick 推进准备、蓄力、释放、生效、恢复、格挡、硬直和倒下状态。COM 依据权威碰撞候选决议同一击是否生效。受击者由完整实体句柄标识，命中记录覆盖整个有效窗口。同 tick 先判断所有接触，再扣除生命，双方可以同时倒下。对同一 tick 的重复调用会被拒绝。调用方可先在 fork 上运行，全部权威阶段成功后再发布该实例。

动作时长、充能和基础点数是模块内的演练数值。后续装配需接入正式编译动作定义及授权的玩家/AI 输入。只改动 COM 导航和实现、专属测试、此报告。未更改 v1 公共字段或存档。
