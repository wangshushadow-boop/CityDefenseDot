# P2-MOV-002 · 野战移动与窄道通行

状态 CANDIDATE · 开发者 `nav` · 基线 `cdfe8eb6d507ef680c1d52bd28badb7ff5453b3b` · 工作树 `.worktrees/p2-movement2`。前置为 GATE-P1 与 P2-MOV-001。关联 BAI-02、BAI-06、COM-04、NAV-01，依据 [MOV 规格](../../../docs/systems/game/mission/movement/README.md)。

## 交付

[野战移动门面](../../../game/mission/movement/ports/field_movement.gd) 通过已有 PathQueue 取得带版本的共享路线。每个 Mission 的 MOV 实例拥有位置、速度、朝向与移动目标进度。注册与移除检查 handle 的 index 和 generation，重复或旧 generation 不能复用。动态导航等待期间停止移动，旧路径弃用，开放后重查。调用方提供已经 FORM 投影的末端槽位，中间路点沿共享走廊行进。

步兵按局部空间格检测移动线段和邻近身体，等待后尝试限速侧移。每次候选位移最多检查 48 个邻居，超额让行。骑兵加速、制动与转向角按速度和固定步长约束；通道可以声明步/骑准入。场景几何来自 INF-ENGINE，中间状态留在 MOV。模块导航、场景、测试、生产代码与本报告均在白名单范围内。没有修改公共契约。
