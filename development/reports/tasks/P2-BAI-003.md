# P2-BAI-003 密集战斗意图与只读战况投影

开发候选 CANDIDATE。模块 COM，需求 BAI-06、COM-05，用例 T-COM-01、T-COM-02、T-COM-05。开发者 combatbatch 使用独立工作区 `.worktrees/p2-combat_batch`，基线 `7042c28`。独立审查、独立 QA 和主分支集成由主 Agent 登记。

## 行为和变更

- `game/mission/combat/melee.gd` 在同一权威入口识别完全符合冻结形状的四向格挡与攻击，包括字段数量、每个键和值的具体类型、代际、数值边界和可空目标。其他表示交给既有 v1 校验器，保留具体错误及合法扩展值在领域层得到的回执。攻击、装备、格挡、伤害仍经过原有状态机。发生结构或物理查询失败时，时钟索引与候选角色行一同丢弃。
- 仅 Windup、Active、Recovery、Stagger 需要检查自动相位转移。时钟索引在提交的命中、取消、溃退、落马和实体退场时同步。fork 复制索引。
- `game/mission/combat/ports/field_combat.gd` 提供本机装配读 `Combat.new(mission_id).field_view(mission_id, handles, projectile_limit=1024)`，已有无参构造及原有单体查询继续工作。批读按给定顺序返回冻结角色行、当前 tick 及飞行中弹体。拒绝错作用域、重复和失代句柄，每次最多 4096 个角色、4096 个弹体。弹体字段为稳定 id、米制位置和单位方向，按发射顺序保留前 N 项，并返回总数。缓存复用同一不可变权威行，退场释放；fork 后修改一方不改变另一方的快照。该查询供本地战场装配使用。
- `game/tests/p2/combat_batch/run.gd` 覆盖 v1 错误完全相等、合法但非法动作、重复 tick/意图、错作用域、代际、飞行器限额/方向/落地、退场、不可变快照、分叉与回滚、落马计时和批读成本。新增逐轮原始指标在 [load-results.json](../../../game/tests/p2/combat_batch/load-results.json)。所有变更限于任务允许的 COM、专用测试和本报告；无 wire、持久格式或架构变更。
