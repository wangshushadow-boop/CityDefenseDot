# P1-PERSIST-CORE-002 关键赛果归档

下游复核发现，单个 v1 存档的第 65,537 个关键赛果会超过规范 JSON 的单容器容量。SaveService 继续按原规则处理每条事实的标识、摘要和原提交号。写盘时按排序后的键每 4,096 条分一页，读取兼容已生成的平面索引。各页重复 ID、非法键或损坏事实均拒绝。上层查询和提交仍获得同一组回执。

在 Godot 4.7.2 下运行 `--headless --script res://tests/p1/persistence/ledger_pages.gd` 退出 0。65,537 个合成事实分成 17 页，9,295,179 个规范字节经解码全部对应原值。旧平面、跨页重复的正反用例通过。原存档模块 run.gd 的 27 个真实子进程回归退出 0。独立审查另从带 4,097 个事实的合规存档实跑幂等、冲突、新赛果原子提交及 4,098 条的冷恢复。该用例单独验证历史长度，未逐个写盘 65,537 次。
