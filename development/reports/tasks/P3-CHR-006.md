# P3-CHR-006 · 建角与人物界面

UI 候选，基线 `650adc4`，开发者 desktop。展示端口为 `game/presentation/ui/ports/character_panel.gd`。面板只持有画面选择、只读人物数据以及受限的会话查询和命令回调。合法性、伤势、经验、库存归属、人物继承及回执均由原领域提交。

玩家可命名建角并选择年龄、文化、童年、行当、开局身份、外观与家纹。人物志显示实际属性、学习进度、软限、互斥天赋、加成来源和生命状态。外观预览复用项目中已有的人物模型、顶点色和 Idle 姿势。弓、弩、投掷根据真实指针位置或方向键准星送出归一化坐标。其他研习展示当前权威题面并提交所选答案。家人页允许明确选择合法继任人或结束生涯；确认前取消不会写存档。

使用 `Godot --path game --script res://tests/p3/character_desktop/run.gd` 在真实 960×600 Windows 窗口执行。原生指针打开建角、命名、选择形象及确认，完成实练、跨阈升级、分配专精、选择天赋、换装、休养一日、取消退休、合法继任、读档以及无继任人结束。指针真实脱靶消耗 15 分钟且没有弓术经验，命中靶心后经验增加；第二个目标由原生方向键移动准星并回车命中。另检查弩、投掷均有靶场。最终 88 项通过，退出 0。

在独立工作区 `out/p3-user/` 实际抓取并核对 `create.png`、`growth.png`、`aim.png`、`equipment.png`、`ended.png`。其中靶场图的 SHA-256 为 `f64ddbf21579fb328306bc55c0c3ca7f8d03de80c6dd630a033349d00b5ed0a2`。首版用信号触发测试时未发现建角表单标签挤压。改为引擎真实指针坐标后原用例失败，修订布局并实际复跑通过。最终版本也显示真实技能是否获得经验及领域返回的卸装拒绝原因。键盘已测；未执行物理手柄、屏幕朗读器及真人体验验收。
