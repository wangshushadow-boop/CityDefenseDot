# P2-RULES-FIELD-001 · 野战胜负、撤退与退出边界

开发人为主 Agent，独立工作树 p2-rules，基线 `2392856`。权威规则挂在 Mission 的 objectives 相位。使用 ADR-014 的带类型队伍键与已预留槽，按是否还有可战或未动员兵力判断野战胜负、平局。溃逃者抵达本队退场区后按当步授权生成退场事实。撤退需要可信控制器授权，退出与事务失败按 Mission 的 commit/rollback 钩子处理。受关注的指挥者倒地后可选择观战、委派或撤退；实体与持久角色身份仍由各自原有模块管理。

Godot 4.7.2 Standard，在本任务工作树运行 `Godot --headless --path game --script res://tests/p2/rules/run.gd`，退出 0，28 个断言通过。实际 Godot 物理命中一名低生命测试角色，COM 给出击倒后，RULES 产生唯一获胜方。实跑旧快照、含预备队的两阵营、拒绝冒用控制权、同 tick 回滚与重试、真实 MOV 出口位置、已倒地主角的选项及模式切换。原有 P2 Mission、COM、P1 应用回归另由主 Agent 保存合并态结果。依赖门禁退出 0。

本阶段仅覆盖 T-RULES-01 至 03 的野战切片。完整村庄、藏身处、访问、竞技、潜入、剧情、攻城与多人规则未执行。实际 HUD、战役持久回写及完整 AT-04/05 留在对应阶段或集成工作包。

独立审查复现了错队指挥官、回滚之后撤权仍生效，以及三方局中普通队长结束整场。候选现按来源槽归属验证指挥官，对待提交命令重查当前权限，并逐方结算普通队长的离场。回归含多方同时请求、真实撤权、预备队、失能事实及不重复发布。ADR-015 的整场主持人决策仍待负责人确认；本候选暂不纳入主分支。
