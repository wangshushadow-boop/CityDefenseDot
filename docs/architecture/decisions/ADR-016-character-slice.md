# ADR-016 · 提前交付 P3 人物

2026-11-25，负责人明确“p2性能后面再优化先完成功能，现在开始完成p3的人物，遇到需要决定的就参考骑马与砍杀游戏中的做法来完成”。这项批准允许单独启动 P3-CHR 和必要的客户端、应用与持久化接入。GATE-P2 仍为 BLOCKED；其余工作包继续按原依赖执行。

## 人物与战役

沿用 Campaign、GameSession、INV 和原子存档。人物仓库在既有世界快照中使用有版本的可选 characters 字段，版本 1。旧世界缺此字段表示尚未创建人物，读取时保留已有库存、世界、会话与回执。未知人物版本拒绝加载。启动时验证原创规则，存档保留人物事实和规则版本。换装以 INV 唯一实例持有者为准。所有人物、装备、家族控制权和回执在同一事务公布。独立战场不会授予战役人物奖励。

采用使用技能获得经验、属性和专精影响学习、天赋分支择一、作用域加成。生涯由文化、年龄、童年、职业、身份、外观和家纹决定。战斗与便装分别配置。伤病与囚禁独立，死亡和退休为终态。退休可从合法成年家族成员中选择继任者或结束生涯；随身物与家产按归属交接。曲线、名称、装备和背景均为原创。无风险训练收益递减。采用这些默认玩法的依据为[开发商人物成长说明](https://www.taleworlds.com/en/Games/Bannerlord/Blog/74)与[退休机制说明](https://www.taleworlds.com/en/News/526)。

本次验证 T-CHR-01 至 04。家族完整婚育、封地、军队和任务继承属于后续工作包。详见[执行计划](../../../development/planning/P3-character.md)。
