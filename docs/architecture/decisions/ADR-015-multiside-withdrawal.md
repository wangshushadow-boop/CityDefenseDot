# ADR-015 · 三方及以上野战中一方撤退的结算边界

**APPROVED，2026-11-25，项目负责人回复 A。** 三方及以上野战中，撤退只撤出发令方，剩余各方继续至自然胜负。主持人参与战斗时遵循同一规则。 ADR-014 固定了每个来源槽的所属方。此次决定涉及 RULES、MIS-RT、RESULTS 和未来战役回写，在冻结的 v1 结果字段内处理。

总体规格 §10.3/10.4 要求按方管理退出、增援和胜负，AT-05 验证玩家撤退后的每槽唯一结果。规格没有指定有三支相互敌对的部队时，有本方权限的玩家撤退是否同时结束其余两方的 Mission。候选 03bae6e 的实现中，任何一方撤退都终止整个场景；独立审查已在该分支定位此处，剩余两方没有决出胜负。

| 方案 | 三方野战里玩家命令本方撤退时 | 两方野战与兼容性 |
|---|---|---|
| A，已批准 | 仅撤出该方，停止该方增援，其他双方继续至自然胜负；退出方的已生成单位保留撤离、受伤/击倒等事实，未生成者保持未入场。仅当剩余不超过一方有可战力量或预备队时，产生整场唯一结果。全局行政结束沿用独立权威入口。 | 两方撤退仍结束整场并产生胜方；不改变外部 v1 结构。 |
| B | 玩家若另具整场主持权限，可在自己撤退时一并结束全场；其他仍能作战的队伍记录本场终止，胜方未定。一方普通队长仍只能退出本方。 | 需对结算消费者约定“已终止、无胜方”，战役的俘虏和奖励需区分这种结果。 |

无论选项，权限不得来自客户端自报，撤退不能产生外队的虚构伤亡。回归需要同一阵营数值键与同文字符串键、三方并存、本方已入场/未入场、同时撤退与失败回滚。P3 的战略结算仍按单独阶段实施。
