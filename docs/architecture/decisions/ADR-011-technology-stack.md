# ADR-011 — P0 候选技术栈与性能基线

**PROPOSED，等待项目负责人批准。** 2026-11-24。关联 GDD §16、§19、§22、§23 及 ADR-004/006/008。用户指定的 Standard 安装已按可执行文件散列验证。

| 待批决策 | 推荐与实测依据 |
|---|---|
| 引擎和主语言 | Windows x86_64 首个验证平台。采用 Godot Standard **4.7.2.stable.official.ed1daf0bf**、类型化 GDScript；客户端 Forward+ / Vulkan，专服使用同版 headless。Godot 主程序 SHA-256 为 `AB1824F85BFD8E0E4128182C000C4003A3E042245B2967848D089B2A04B22424`。指定二进制直接跑通图形、导航、专服、编辑器导入和 PCK 重载。 |
| 热路径 | 保留单一权威模拟与引擎适配器，先优化数据布局和算法。独立 GDScript/引擎路径已承载本次负载。C++ GDExtension 仅在 profiler 找到超预算热点后提交专项实验和 ADR。C# 需要另一个 .NET 构建；其他引擎及主语言均未做同场跑分。 |
| 帧率与采样 | 在 Intel Core Ultra 9 285K、32 GB 级内存、RTX 3090 24 GiB、591.86 驱动实测，1080p、VSync 关闭、MSAA 2× 和 2048 阴影。双方等额混合步/弓/骑，单人 60 Hz，种子 241124。按 GDD 维持 500 人 ≥60 FPS / 帧 P95 ≤20 ms，1000 人 ≥30 FPS / 帧 P95 ≤40 ms，固定 tick P95 低于步长且无持续积压。 |
| 资产代表性 | 原创人和马各有独立蒙皮、7 骨、1,344 三角形。修正版逐 tick 盘点在镜并保持存活的人形与坐骑，单独计入在途弹体和倒地尸体。P0 可接受基于这个明确负载的可行性结论。带正式材质、装备与场景的中画质表现及 8 GiB 设备驻留另行实测。若负责人要求更高负载作为 P0 基准，保留本次数据后在相同门槛补测。 |
| 导航和网络 | NavigationServer3D + 局部动态链接，在可达性和导航修订号同步后使用共享路径。专服 ENet/UDP 权威，30 Hz tick、15 Hz 快照；传输层与模式逻辑分离。64/128 个样本使用真实、合成驱动的本机连接。建议本轮受限回溯候选上限 6 步（200 ms），历史窗口含当前在内 7 个样本；服务器决定可接受时间，近战/盾牌/格挡使用同一时刻，弹体从历史释放点向前权威模拟。生产公平性、跨网表现和完整战斗负载需 P6 复验。 |
| 构建、工具与测试 | 本机 Python 3.12.14 标准库组织可重复 CLI、unittest 和集成检查；Godot 自身运行 headless 检查并返回显式失败码。P1 候选 CI 顺序为架构检查、纯领域向量、Godot 导入与引擎测试、针对集成构建的启动检查；标准版本一致后才接发布导出。P0 实跑 PCK；本机缺少默认位置的零售导出模板。没有引入外部测试框架。 |
| 内容与发布平台 | 先用 glTF 2.0、米制与 Y-up，查验实际导入后的蒙皮、动作窗口、确切武器/坐骑挂点、出生/通行标记、来源和许可；定义验证成功后再编译。PCK 接口已验证。DCC 选型、正式角色骨架、批量内容标准与其他平台发布不在本轮冻结范围。 |
| 数据边界 | 采用 ADR-012 的纯数据与独立版本提案。Godot 默认 JSON 会将 `1` 与 `1.0` 读成同一种 float，并丢失重复键。规范线消息需保留输入字节并按 schema 校验；允许宽松排版的编辑源必须在语法层检查重复键与数值。P0 已有局部互通向量，P1 按完整 schema 与 Unicode NFC 复验。 |

### 各方如何复核

本轮结论比较两版战场负载、不同人数、关开门状态、故障与无故障链路以及不同连接数。替代语言、引擎、渲染后端的性能没有排名。技术基线只覆盖已测原始内容与主机，引用实测摘要及主管审批后才生效。[环境](../../../development/reports/tasks/P0-ENV-001.md) · [战场](../../../development/reports/tasks/P0-BATTLE-001.md) · [导航](../../../development/reports/tasks/P0-NAV-001.md) · [网络容量](../../../development/reports/tasks/P0-NET-002.md) · [内容](../../../development/reports/tasks/P0-CONTENT-001.md) · [互操作](../../../development/reports/tasks/P0-CONTRACTS-002.md)
