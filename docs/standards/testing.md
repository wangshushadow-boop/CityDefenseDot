# 测试、构建与性能规范

[原验收矩阵](../testing/acceptance_matrix.md) 和 `test_cases.csv` 为最低判据，不得改低。用例给出前置、操作、精确断言、失败路径、固定种子、环境。单元/属性→集成→场景→端到端→长时压力/故障注入；区分 mock 与真实系统。每次记录 commit、内容 hash、引擎版本、命令、退出码、运行/失败/跳过数、报告路径。NOT_RUN 与 FAIL 不可当 PASS；仅通过文档脚本不代表游戏通过。性能按 §19.4/22.3，记录 CPU/GPU、驱动、分辨率、实际人数/角色/动画/导航、帧时间 P50/P95/P99、模拟积压、内存、重复次数；P0 冻结基准，默认不降低 500/1000 人目标。P1 选真实构建命令接入 CI；P7 人工试玩、功能/内容/授权、发行及迁移验收。
