# 内容、资产及制作规范

以总体设计 §15、§21 及 [BASE 规格](../systems/game/content/base/README.md) 为基准。资产标准必须早于批量生产冻结：统一角色/马匹骨架与体型、武器握持及挂载点、世界米制尺度与坐标、碰撞代理、动作窗口、材质/LOD、纹理预算、地形/导航和出入口标记、命名、本地化键、音频事件。可用占位资源做隔离的技术实验，不能作为正式交付内容。原创文化/世界/剧情另由内容任务设计，不抄原作。资产元数据至少记录稳定 ID、类别、来源、作者、许可、版本、资源路径、骨架/插槽、预算与校验结果。正式导入/编译拒绝缺引用、缺授权、非法碰撞和无有效导航。P0/P1 冻结具体尺寸、骨架版本与工具；不得把未评审假定写成已定标准。
